This package contains **no match or ranking data**. Everything below is
downloaded by the user into `data-raw/csv/`, which is in `.gitignore`.

## Why a mirror

Checked on 2026-09-04: `JeffSackmann/tennis_atp` returns HTTP 404, as do
`tennis_wta` and `tennis_slam_pointbypoint`. Only
`tennis_MatchChartingProject` remains on that account. The reason is not
visible from outside.

`Aneeshers/tennis-sackmann-archive` is an archival mirror created on
2026-06-25. It states that it holds data only, carries CC BY-NC-SA 4.0, keeps
the upstream README as `UPSTREAM_README.md`, and attributes Jeff Sackmann.

Because the upstream is gone, **the data set is frozen**. The published
analysis stays reproducible; it cannot be brought forward without a new source.

## Licence separation

- The **MIT licence in `LICENSE` covers the package code only.**
- The **source data is CC BY-NC-SA 4.0** and is not redistributed here.
- All committed test fixtures are **synthetic**, generated by
  `tests/testthat/fixtures/make_synthetic.R` and `make_season.R`. No row of
  them derives from any real data set, so they carry the same MIT licence as
  the code.

Anyone downloading and processing this data is responsible for complying with
the source licence themselves. Non-commercial use and attribution to Jeff
Sackmann are required.

## Provenance

`data-raw/download_matches.R` and `data-raw/download_rankings.R` print source,
licence and attribution before downloading, and write `MANIFEST.csv` next to
the files recording, for every file:

- the URL it came from
- the size in bytes
- a **SHA-256 checksum**
- the retrieval timestamp
- the **commit id of the mirror** at the time of retrieval

The manifest is what makes a published result checkable: it says exactly which
bytes produced it. It is ignored by git along with the data.

## Reference rating lists

`analysis/validate-external.R` can compare these ratings against a published
Elo list, if the user supplies one. Such a list is never committed —
`reference/` is in `.gitignore` — which keeps the licensing question about
third-party rating data out of this repository.
